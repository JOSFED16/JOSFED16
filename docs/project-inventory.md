- Proyecto principal.
- Proyecto complementario.
- Práctica técnica.
- Proyecto académico que debe mejorarse.
- Proyecto que no conviene publicar.

## Criterio de publicación

Un proyecto solamente se considerará publicable cuando tenga:

- Problema claramente definido.
- Código funcional.
- Instrucciones de instalación.
- Variables de entorno protegidas.
- Pruebas básicas.
- README específico.
- Historial de commits comprensible.
- Capturas o demostración.
- Datos ficticios o anonimizados.
- Licencia y estado del proyecto.
